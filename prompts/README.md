# prompts

The prompts driving work in this repository, and the deliverables they produced. Working
material: outside the knowledge base, binding nothing, kept as the record of why the tree looks
the way it does.

- **Format:** `{{kb.root}}/framework/templates/artifacts/prompt.md.template` — the sections a
  prompt is expected to carry, and why each one exists. A prompt an agent has to guess at
  produces work you then have to guess at.
- **Naming:** `YYYY-MM-DD-<imperative-slug>.md`. A deliverable produced by a prompt keeps the
  prompt's date and adds what it is: `YYYY-MM-DD-<slug>-analysis.md`.
- **Chaining:** a prompt whose output feeds another says so in its Output section, and the
  consumer names its input in its Inputs section. The chain is the traceability record.

`{{kb.root}}` is the knowledge base's location in this repository — stated in `CLAUDE.md`.
