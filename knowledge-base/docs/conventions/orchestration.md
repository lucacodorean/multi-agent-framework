# Orchestration model — moved

Pointer stub. This convention has its homes in the core and in the context, and no third copy
(FI-01). Nothing here restates either.

- **Rules** — operating model, tiers and direction, contract-first sequence, deterministic
  pipelines, dispatch mechanics, model and effort: `framework/rules/orchestration.md`.
- **Channels** — which route a requirement, constraint, doc impact, review, report, checkpoint
  or escalation travels through, and the rules holding on all of them:
  `framework/rules/agent-communication.md`.
- **Membership** — who exists, the tier order, each member's mandate: `framework/roster.md`.
- **Harness spellings** — dispatch primitives, model map, effort map, capability gaps:
  `framework/hosts/`.
- **Project values** — per-member ownership: `project-context/roster.md`; gate serialization:
  `project-context/ci.md`; verification commands: `project-context/commands.md`.
