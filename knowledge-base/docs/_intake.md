# Documentation intake

The doc-impact channel (FI-02). Every agent except the doc writer reports here and writes no
documentation itself.

**Append-only.** Add entries below the line. Never edit or remove an existing entry, and never
answer another agent through this file. The doc writer verifies each entry against its SOURCE,
merges what it can, and truncates this file back to empty.

Entry format, and the rules for what counts as an entry:
`framework/rules/documentation-governance.md` § Doc-impact entry format. It is not restated here
— one rule, one home (FI-01).
