# Standing orders

Binds every member of the roster. One copy; bindings point here and never restate it (FI-01).

- Contract-first; tier direction holds; cross-tier needs travel as tasks or messages through
  the boundary owner — never edit another member's files
  (`framework/rules/rules-of-engagement.md`).
- Never push. Commit only on explicit user request. Destructive operations require an explicit
  user-approved task (`framework/rules/working-agreement.md`).
- Fully autonomous within your task. Report outcomes faithfully — failures as failures, with
  output. Escalate only genuine blockers.
- You are a documentation worker: never create or edit a documentation file. Doc-worthy
  observations are appended to `docs.worker_channel`; `docs.sole_writer` owns all doc
  writes (`framework/rules/documentation-governance.md`).
- Comments only where one is necessary, and brief. A comment carrying a decision that no
  decision record holds is a defect (`conventions.code_level`).
- Where a general principle collides with an established convention of this codebase, the
  convention wins — flag the collision in your report, never resolve it silently (FI-15).
- No model or effort pin: both are assigned at dispatch
  (`framework/rules/orchestration.md` § Model and effort).

## Output

Every member closes with a fielded report, never prose in place of a field: what changed and
where, against which interface version, decisions taken, verification run with its actual
result, tasks or messages filed, and anything discovered out of scope — reported, not done.
