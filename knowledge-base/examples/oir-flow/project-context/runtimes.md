- `runtimes.shared_inputs_dir`: `infra/shared/` — Redis config and the engine image definition
  with its dependency lock. No runtime holds a copy; no runtime resolves a path into another
  runtime's directory.
- `runtimes.generated_dirs`: `.ddev/` — generated by `infra/ddev/bootstrap.sh`.

## Known behaviours

- `.env` is volatile: `ddev start`/`restart` rewrite keys in it. Durable configuration goes to
  `config/**`, `.env.example`, or `.ddev/config.local.yaml`.
- The engine has no hot reload (uvicorn runs without `--reload`, source bind-mounted
  read-only). An engine-source-only change needs `docker restart ddev-oir-flow-engine`; a
  topology change needs the full boot.
- `ddev restart` can exit green while containers still run the old topology.
- Host prerequisites: Docker plus the CLI of the runtime being used (ddev ≥ 1.23.5 per
  `infra/ddev/bootstrap.sh`). Every other tool runs in a container.
- Further gotchas, including the standing `NEPROVIZIONAT oir-north` boot summary:
  `docs/runbook.md` § Gotchas.
